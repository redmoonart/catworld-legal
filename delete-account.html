CatWorld Account Deletion

This page allows CatWorld users to request deletion of their account and associated personal data.

How to Request Account Deletion

To request deletion of your CatWorld account, send an email to:

catworld.app88@gmail.com

Please use the subject: CatWorld Account Deletion Request

Request Account Deletion
Important: For security, we may need to verify that the request belongs to the CatWorld account owner before processing the deletion.

What Will Be Deleted

When an account deletion request is successfully processed, CatWorld will delete the account information associated with the user, including:

  • Firebase Authentication account.
  • User profile information stored in Firebase Firestore.
