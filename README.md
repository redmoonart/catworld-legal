# Kids of the Future — متجر ألعاب الأطفال والأدوات المدرسية 🧸🎒

متجر إلكتروني احترافي لبيع **ألعاب الأطفال** و**الأدوات المدرسية** في **الجزائر**، مبني بـ
**React + Vite + Framer Motion**، ثلاثي اللغة (عربي/فرنسي/إنجليزي) بواجهة ثلاثية الأبعاد
وحركات احترافية، ويُنشر مجاناً على **GitHub Pages**.

## ✨ المميزات

- تصميم احترافي ثلاثي الأبعاد (React + Framer Motion)، متجاوب مع الهاتف، وباتجاه من اليمين
  لليسار (RTL) بالعربية افتراضياً.
- سلة تسوّق تُحفظ في متصفح الزائر (localStorage) — لا تحتاج خادماً.
- الطلب عبر **واتساب**: يُبنى نص الطلب تلقائياً (المنتجات + العنوان + السعر) ويُرسل لرقمك.
- **الدفع عند الاستلام** (Cash on Delivery).
- التوصيل لكل **58 ولاية** جزائرية مع سعر توصيل لكل ولاية (منزل / مكتب).
- توصيل مجاني فوق مبلغ يمكنك تحديده.
- بحث، فلترة حسب الفئة، وترتيب حسب السعر/الاسم.
- صفحات: الرئيسية، المتجر، تفاصيل المنتج، السلة، من نحن، اتصل بنا (+ أسئلة شائعة).

## 🗂️ هيكل المشروع

```
index.html                نقطة دخول Vite
src/main.jsx               تشغيل التطبيق (React Router + Providers)
src/App.jsx                التوجيه بين الصفحات (Routes)
src/pages/                 الصفحات: Home, Shop, Product, Cart, About, Contact
src/components/            المكوّنات: Header, Footer, ProductCard, Hero3D...
src/i18n/                  نظام تعدّد اللغات (I18nContext + strings.js)
src/cart/                  إدارة السلة (CartContext)
src/toast/                 إشعارات ToastContext
src/data/config.js         ⚙️ إعدادات المتجر (الاسم، رقم واتساب، التوصيل...)
src/data/products.js       📦 قائمة المنتجات
src/data/wilayas.js        🗺️ الولايات وأسعار التوصيل
src/styles/global.css      التصميم
public/                    ملفات قانونية ثابتة (privacy-policy.html...)
```

## ⚙️ الإعداد (خطوة واحدة مهمة)

افتح `src/data/config.js` وضع **رقم واتساب متجرك** بصيغة دولية بدون `+` وبدون الصفر الأول:

```js
// الرقم 0555 12 34 56  →  يُكتب هكذا:
whatsapp: "213555123456",
```

يمكنك من نفس الملف تغيير اسم المتجر، البريد، روابط التواصل، سعر التوصيل الافتراضي،
وحدّ التوصيل المجاني.

## ➕ إضافة / تعديل المنتجات

عدّل `src/data/products.js`. انسخ كتلة منتج وغيّر القيم:

```js
{ id: 300, category: "toys", name: "اسم المنتج", emoji: "🎁",
  price: 2500, oldPrice: 3000, badge: "جديد", stock: true,
  desc: "وصف المنتج" },
```

- `category`: `"toys"` (ألعاب) أو `"school"` (أدوات مدرسية).
- `id` يجب أن يكون فريداً.

## 🚚 أسعار التوصيل

عدّل `src/data/wilayas.js` لضبط سعر التوصيل لكل ولاية (`home` للمنزل، `office` للمكتب)
حسب اتفاقك مع شركة التوصيل.

## 💻 التطوير محلياً

```bash
npm install
npm run dev      # خادم تطوير محلي
npm run build    # بناء نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج محلياً
```

## 🌐 النشر على GitHub Pages (مجاناً)

النشر تلقائي عبر GitHub Actions (`.github/workflows/deploy-pages.yml`): كل دفعة (push) إلى
فرع `main` تُبني المشروع بـ Vite وتُنشر مجلد `dist/` على GitHub Pages مباشرة.

> ملاحظة: كل شيء يعمل من جهة المتصفح فقط (SPA)، لذلك لا توجد أي تكاليف استضافة.
