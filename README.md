# Kids of the Future — متجر ألعاب الأطفال والأدوات المدرسية 🧸🎒

متجر إلكتروني احترافي لبيع **ألعاب الأطفال** و**الأدوات المدرسية** في **الجزائر**، مبني بالكامل
بتقنيات مجانية (HTML / CSS / JavaScript) بدون أي خادم أو قاعدة بيانات — يعمل مباشرة على
**GitHub Pages** مجاناً.

## ✨ المميزات

- تصميم احترافي، متجاوب مع الهاتف، وباتجاه من اليمين لليسار (RTL) بالعربية.
- سلة تسوّق تُحفظ في متصفح الزائر (localStorage) — لا تحتاج خادماً.
- الطلب عبر **واتساب**: يُبنى نص الطلب تلقائياً (المنتجات + العنوان + السعر) ويُرسل لرقمك.
- **الدفع عند الاستلام** (Cash on Delivery).
- التوصيل لكل **58 ولاية** جزائرية مع سعر توصيل لكل ولاية (منزل / مكتب).
- توصيل مجاني فوق مبلغ يمكنك تحديده.
- بحث، فلترة حسب الفئة، وترتيب حسب السعر/الاسم.
- صفحات: الرئيسية، المتجر، تفاصيل المنتج، السلة، من نحن، اتصل بنا (+ أسئلة شائعة).

## 🗂️ هيكل الملفات

```
index.html            الصفحة الرئيسية
shop.html             صفحة المتجر (كل المنتجات + فلترة وبحث)
product.html          صفحة تفاصيل المنتج (product.html?id=101)
cart.html             السلة وإتمام الطلب عبر واتساب
about.html            من نحن
contact.html          اتصل بنا + الأسئلة الشائعة
legal.html            صفحة معلومات CatWorld القانونية (محفوظة)
privacy-policy.html   سياسة الخصوصية
delete-account.html   طلب حذف الحساب
assets/css/styles.css  التصميم
assets/js/config.js    ⚙️ إعدادات المتجر (الاسم، رقم واتساب، التوصيل...)
assets/js/products.js  📦 قائمة المنتجات
assets/js/wilayas.js   🗺️ الولايات وأسعار التوصيل
assets/js/store.js     🧠 منطق السلة والطلب والعرض
```

## ⚙️ الإعداد (خطوة واحدة مهمة)

افتح `assets/js/config.js` وضع **رقم واتساب متجرك** بصيغة دولية بدون `+` وبدون الصفر الأول:

```js
// الرقم 0555 12 34 56  →  يُكتب هكذا:
whatsapp: "213555123456",
```

يمكنك من نفس الملف تغيير اسم المتجر، البريد، روابط التواصل، سعر التوصيل الافتراضي،
وحدّ التوصيل المجاني.

## ➕ إضافة / تعديل المنتجات

عدّل `assets/js/products.js`. انسخ كتلة منتج وغيّر القيم:

```js
{ id: 300, category: "toys", name: "اسم المنتج", emoji: "🎁",
  price: 2500, oldPrice: 3000, badge: "جديد", stock: true,
  desc: "وصف المنتج" },
```

- `category`: `"toys"` (ألعاب) أو `"school"` (أدوات مدرسية).
- لإضافة صورة حقيقية: ضع الصورة في `assets/img/` وأضِف الحقل `image: "assets/img/name.jpg"`.
- `id` يجب أن يكون فريداً.

## 🚚 أسعار التوصيل

عدّل `assets/js/wilayas.js` لضبط سعر التوصيل لكل ولاية (`home` للمنزل، `office` للمكتب)
حسب اتفاقك مع شركة التوصيل.

## 🌐 النشر على GitHub Pages (مجاناً)

1. ادفع الملفات إلى المستودع على GitHub.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر الفرع (branch) والمجلد `/ (root)` ثم **Save**.
4. سيصبح الموقع متاحاً على رابط `https://<username>.github.io/<repo>/`.

> ملاحظة: كل شيء يعمل من جهة المتصفح فقط، لذلك لا توجد أي تكاليف استضافة.
